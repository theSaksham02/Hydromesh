## Design Context

### Users
Municipal agencies, disaster coordinators, grant and UN-adjacent evaluators. They need a UNDP-grade civic briefing — white canvas, sharp geometry, sourced tables — without HydroMesh impersonating a UN body.

### Brand Personality
Objective, institutional, urgent. Senior DRR officer voice. No hype.

### Aesthetic Direction
UNDP Design System (design.undp.org) + Swiss typographic discipline. White `#FFFFFF` / tint `#F7F7F7`, midnight footer `#08182B`, brand `#006EB5`, ink `#1A1A1A`, muted `#55606E`, hairlines `#D4D7DC`. Radii `0` or `2px`. Source Sans 3 + JetBrains Mono. No pills, no serif display, no teal leftover, no Kindlink, no empty frames.

### Design Principles
1. **UNDP tokens, HydroMesh facts.** Visual language from UNDP. Copy and metrics only from the repo and verified credentials.
2. **Do not impersonate the UN.** No UN/UNDP emblem. State independence. SDG 11.5 is an alignment, not a mandate.
3. **Data-to-ink.** Tables, cadastral schematic, document grid. Hairlines, not shadows.
4. **WCAG 2.2 AA.** `focus-visible:ring-2 focus-visible:ring-[#006EB5] focus-visible:ring-offset-2`. 44px targets.
5. **Native CSS only.** `transition-colors duration-150 ease-out`. No Framer Motion.
